Python · PyTorch · Bioinformatics · 2025

Protein-Protein Interaction Propensity from Coarse Structural Features

A machine learning project exploring whether coarse-grained structural properties of proteins retain predictive signal for protein-protein interaction participation. Compared a logistic regression baseline against a PyTorch neural network, with the MLP achieving ROC-AUC of ~0.80. Leakage diagnosis and correction were central to the analysis.

Python · Machine Learning · 2024

NBA Salary Predictor

A machine learning project predicting NBA player salaries using 2022-23 season data. Built and compared multiple models including Random Forest, XGBoost, and ensemble methods like stacking and voting regressors. Random Forest emerged as the top performer, with Age and Total Minutes as the strongest salary predictors.
